# Possistem website

Current Next.js website source. Use Node 22, `npm ci`, `npm run build`, `npm start`. Production API remains on the same origin at `/pos/api/`.

`public/assets` includes the existing brand and marketing images. The large generated POS demos under `public/pos-demo-app` are retained on the server and built from the desktop demo sources; they are not regenerated by this payment release.

The `/odenis` routes use authenticated API quotes and server-confirmed payment results. Epoint keys must never be added here. See `../docs/EPOINT-BILLING-20261024.md` for setup.
