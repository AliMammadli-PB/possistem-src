# Restoran POS 1.10.0

- **Kalkulyasiya.** Xammalı alış qiymətini boş qoyaraq reseptə əlavə etmək olur. Anbarda yeni mal standart olaraq satışa çıxarılmır.
- **Mövcud ölçülər.** Kataloqda eyni kateqoriyadakı məhsulları seçib “Ölçüləri birləşdir” əməliyyatını açın. Satışda görünən adı və hər məhsulun ölçüsünü yazın. Qiymət, resept, stok bağlantısı və məhsul identifikatoru qorunur.
- **Windows ikonu.** Mavi Possistem nişanı tətbiq pəncərəsi və Windows icra faylına daxil edilib.
- 1.9.37-dəki printer uyğunluğu və müştəri çeki düzəlişləri də yığıma daxildir.

380 nüvə testi Wine üzərində keçdi. Ekran sınağında mövcud pizzalar birləşdirildi, hər iki ölçü sifarişə əlavə edildi və alış qiyməti boş saxlanan un resepti yadda saxlandı. Kassa sınağında iki ölçünün ödənişi bağlananda 1 kq undan ardıcıl 200 və 300 qram çıxıldı.

Windows x64 quraşdırıcısı və ZIP arxivinin bütövlüyü yoxlandı. Avtomatik yeniləmə manifesti Possistem imzası ilə yayımlanır. Windows kod sertifikatı və fiziki Windows cihazı ilə sınaq bu buraxılışda mövcud deyildi.
