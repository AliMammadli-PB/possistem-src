# Restaurant POS 1.9.17 — branch packaging, subscription entry and Xprinter

Released for manual pilot download on 2026-10-29. Market POS remains 1.5.74.

## Changes

- Package the missing `branch-presence.cjs` dependency used by cloud branches. Assembly now verifies all relative main-process requires before packaging.
- Check the owner's Restaurant subscription before rendering or accepting PIN login. Unpaid customers see a website payment action after email sign-in. Main-process direct/nested batch calls and billing-managed native login enforce the barrier. An unexpired, customer-matching signed billing license provides offline access; rejected server sessions do not use that fallback.
- Remove visible 10-digit/local administrator/first-install PIN hints and the redundant mode switch. Existing PIN values are not reset.
- Add Ethernet Xprinter discovery and static IP, subnet mask and gateway configuration under Settings → Printer. Select a discovered MAC, enter addresses and confirm the change. Configuration is successful only after reading back all settings. An unconfirmed command is reported as unconfirmed. Changes require settings.manage and are audited.
- Bundle the official Xprinter ESC Windows SDK 2.1.5 x64 DLL, pin its checksum and load it beside the native executable. See integrations/xprinter/README.md for provenance.

## Install and operator checks

1. Back up the POS database through the application and finish any open sales.
2. Download from https://possistem.az/download/pos/ and close POS before installing 1.9.17 over the existing version. Do not uninstall or delete its data folder.
3. If downloading the ZIP, extract it before running the EXE. No integrity-check bypass is needed.
4. Sign in with the administrator-created email account. If the Restaurant subscription is unpaid, use “Saytda ödəniş et”; after payment use “Ödənişi yoxla”. A billing-only session asks for email sign-in again to obtain full credentials and a refreshed signed license.
5. Confirm that the existing branch assignment and branch list load correctly.
6. For an Ethernet Xprinter on the same LAN, open Settings → Printer → Xprinter — IP və gateway. Discover and select its MAC, choose an unused static address and the LAN's actual mask/gateway, then confirm. After verified readback, update the POS printer target to the new address and print a test receipt. PC network adapter settings are not changed automatically.
