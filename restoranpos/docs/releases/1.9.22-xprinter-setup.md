# Restaurant POS 1.9.22 / Market POS 1.5.77 — Xprinter network setup that works on a real till

Built on 1.9.21 (trial access). Market changes ride on 1.5.76.

## Fixes found on a real Ethernet Xprinter (2026-10-30)
- "Şəbəkədə Xprinter axtar" crashed the core in 1.9.17–1.9.21 and Market 1.5.75–1.5.76:
  `SearchEscNetDevice` in the MSVC-built `printer.sdk.dll` takes an MSVC `std::function` by value,
  not a function pointer. The core now passes a compatible object.
- After `SetEscNetInfo` the printer restarts its network; one read-back after 2 s reported a
  successful change as unconfirmed. The read-back now retries for up to 10 s.

## Setup on any till
- Installers add an inbound Windows Firewall rule for the POS core, UDP 9600 (the printer replies
  to the search by broadcast when it sits on another subnet). Restaurant: "possistem Xprinter",
  Market: "MarketPos Xprinter". Auto-update runs the installer, so existing tills get it.
- If the search finds nothing and the rule is missing (portable copy, removed rule), Settings →
  Printer shows "İcazə ver (Administrator)", which adds it through a Windows UAC prompt.
- The search also returns this PC's networks. A printer on another subnet or gateway gets a warning
  and "Kompüterin şəbəkəsinə uyğunlaşdır" (PC's subnet + printer's host number, PC's mask and gateway).
- An address that another device already answers on is refused before anything is sent.

POSSISTEM super admin (10-digit PIN) already holds settings.manage (Restaurant) / manager rights
(Market), so no role change was needed. The app does not run as Windows administrator.

## Verification
- Real printer MAC 00:61:C6:FA:C1:F3 via the app's core functions under Wine: found at
  192.168.0.176 / gw 192.168.0.1, moved to 192.168.100.176 / gw 192.168.100.1, read back as
  verified, ping and port 9100 answer, test receipt sent. Collision check refused 192.168.100.1.
- Network-match suggestions checked for /24 and /16 and collisions with the PC and gateway.
- Market card checked in a browser with mocked device responses (blocked → permission → match).
- Not exercised: the UAC prompt and installer rule on a real Windows PC.
