# Restaurant POS 1.9.20 / Market POS 1.5.76 — payment entry and admin access grants

The payment screen now reports checking, confirmation, missing product assignment and connection failure visibly. A manual check reconciles existing pending bank transactions using status requests, then imports a fresh device-bound signed license. It never starts another charge. Free/trial access uses an explicit server permission instead of pretending that a bank payment exists.

The desktop handoff opens a payment-only authenticated website session even when no subscription exists. The page identifies the POS customer and product, hides the unrelated browser account header, and validates the customer again before checkout. It does not replace the browser's general customer session. Missing product assignment is explained instead of returning a transport-level subscription-not-found error. Product and customer ownership still gate license activation.

Admin → customer → POS and branches → select a POS, or Billing → subscriptions → access controls:

- Give 1–365 free days. Repeated requests share an idempotency key; existing paid/legacy license time is preserved.
- Open use without a subscription. Automatic collection and current recurring consent stop.
- Restore monthly subscription enforcement. Current paid time remains.
- Remove a subscription from active management while permitting free use. Financial history, original bank references and audit records remain available.

The same controls apply to Restaurant, Market, Clothing, Pharmacy and Wholesale licenses already assigned to that customer. They cannot manufacture a license for an unassigned product. A customer created later can use these controls immediately after its POS license is added.

Migrations 0053 and 0054 add explicit trial/free access and keep the earlier cancellation workflow separate from free grants. Existing saved-card, cancellation-request, partial-refund, order-tracking and support functionality from the running deployment was retained and synchronized into the source tree.

The mobile shop footer uses one continuous patterned surface with a canvas cutout for its wave; responsive padding no longer creates a patterned band above the wave. The public download page offers the new manual test builds and ZIP copies. No unsigned artifact was promoted into a stable automatic update feed.
