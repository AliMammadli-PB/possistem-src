# Third-party assets

Menu imagery for Maison Aurelia demo builds.

## Placeholder WebP files

Generated by `npm run fetch:assets` into
`apps/desktop/src/renderer/assets/menu/*.webp`.

These are tiny 1×1 WebP placeholders so the app builds offline. For a production
look, replace each file with a real dish photograph (recommended 800×600 WebP).

## MarketPos retail catalog

`market-pos/public/assets/marketpos-products-01-v1.png` through
`marketpos-products-05-v1.png` and `marketpos-role-avatars-v1.png` are original
AI-generated raster assets retained for backwards compatibility. The current seed
catalog uses 58 product photographs in `market-pos/public/assets/wolt/`, collected
from the public Bravo Supermarket Wolt catalog on 2026-08-24 at the user's request.
Product names, editable demo prices, photographs, packaging, and trademarks remain
the property of their respective owners and should be cleared for commercial use:
https://wolt.com/az/aze/baku/venue/bravo-supermarket-5-sayli-xestexana

`marketpos-logo-v2.png` and `marketpos-app-icon-v2.png` are original AI-generated
MarketPos branding assets created for this project.
